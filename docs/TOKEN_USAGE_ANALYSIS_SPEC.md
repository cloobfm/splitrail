# Token Usage Analysis Specification

This document specifies the metrics, data sources, analysis methodology, and reporting capabilities for analyzing token usage across all AI coding tools tracked by Splitrail.

## Overview

Splitrail tracks token usage across multiple AI coding assistants to provide insights into:
- Daily and cumulative token consumption (input, output, total)
- Cost analysis based on model-specific pricing
- Usage patterns and benchmarking against industry averages
- Theoretical maximum capacity per tool

---

## 1. Metrics Definitions

### Primary Token Metrics

| Metric | Description | Priority |
|--------|-------------|----------|
| `output_tokens` | Tokens generated by the AI model | **Primary** |
| `input_tokens` | Tokens sent to the model (prompts, context) | Secondary |
| `total_tokens` | Sum of input + output tokens | Derived |
| `cache_read_tokens` | Tokens retrieved from cache (reduced cost) | Informational |
| `cache_creation_tokens` | Tokens written to cache | Informational |
| `reasoning_tokens` | Tokens used for chain-of-thought (o1/o3 models) | Model-specific |

### Aggregation Levels

| Level | Description |
|-------|-------------|
| Per-message | Single API call token counts |
| Per-session | Cumulative tokens within a conversation |
| Per-day | Daily totals across all sessions |
| Per-tool | Aggregate across all days for a specific CLI |
| Cumulative | Grand total across all tools and time |

### Derived Metrics

| Metric | Formula | Use Case |
|--------|---------|----------|
| Input:Output Ratio | `input_tokens / output_tokens` | Efficiency analysis |
| Cost per 1K Output | `total_cost / (output_tokens / 1000)` | Cost efficiency |
| Daily Average | `total_tokens / active_days` | Trend analysis |
| Peak vs Average | `max_daily / avg_daily` | Burst capacity |

## 2. Data Sources

### 2.1 Claude Code

**Path Pattern:**
```
~/.claude/projects/*/*.jsonl
```

**File Format:** JSONL (one JSON object per line)

**Token Fields Location:**
```json
{
  "type": "assistant",
  "message": {
    "usage": {
      "input_tokens": 1234,
      "output_tokens": 567,
      "cache_creation_input_tokens": 100,
      "cache_read_input_tokens": 50
    }
  }
}
```

**Extraction Notes:**
- Usage is nested under `message.usage`, not at top level
- Only `assistant` type messages contain usage data
- Timestamps in `timestamp` field (ISO 8601)

---

### 2.2 Codex CLI

**Path Pattern:**
```
~/.codex/sessions/{YYYY}/{MM}/{DD}/*.jsonl
# Glob: ~/.codex/sessions/*/*/*/*.jsonl
```

**File Format:** JSONL with cumulative and per-message usage

**Token Fields:**
```json
{
  "type": "response",
  "total_token_usage": {
    "input_tokens": 50000,
    "output_tokens": 2500,
    "reasoning_tokens": 0,
    "total_tokens": 52500
  },
  "last_token_usage": {
    "input_tokens": 1000,
    "output_tokens": 150
  }
}
```

**Extraction Notes:**
- `total_token_usage` is **cumulative** within a session
- Take MAX of `total_token_usage` per session file, not SUM
- `last_token_usage` contains per-message incremental tokens
- Supports reasoning models (o1, o3) with `reasoning_tokens`

**Critical Warning:**
```
WRONG: Sum all output_tokens fields → Inflated by 1000x+
RIGHT: Max of total_token_usage.output_tokens per session
```

## 3. Analysis Methodology

### 3.1 Data Extraction Script

```python
#!/usr/bin/env python3
"""
Splitrail Token Usage Analyzer
Extracts and aggregates token usage across all supported AI coding tools.
"""

import json
import re
import os
from glob import glob
from datetime import datetime
from collections import defaultdict
from pathlib import Path

class TokenAnalyzer:
    def __init__(self):
        self.home = str(Path.home())
        self.daily_stats = defaultdict(lambda: defaultdict(lambda: {
            'input': 0, 'output': 0, 'total': 0
        }))

    def analyze_claude_code(self):
        """Extract Claude Code token usage from JSONL files."""
        pattern = f"{self.home}/.claude/projects/*/*.jsonl"

        for filepath in glob(pattern):
            try:
                with open(filepath, 'r') as f:
                    for line in f:
                        try:
                            data = json.loads(line)
                            if data.get('type') == 'assistant':
                                usage = data.get('message', {}).get('usage', {})
                                if usage:
                                    ts = data.get('timestamp', '')
                                    date = ts[:10] if ts else None
                                    if date:
                                        self.daily_stats[date]['claude_code']['input'] += usage.get('input_tokens', 0)
                                        self.daily_stats[date]['claude_code']['output'] += usage.get('output_tokens', 0)
                        except json.JSONDecodeError:
                            continue
            except Exception as e:
                print(f"Error processing {filepath}: {e}")

    def analyze_codex_cli(self):
        """Extract Codex CLI token usage, handling cumulative totals correctly."""
        pattern = f"{self.home}/.codex/sessions/*/*/*.jsonl"

        for filepath in glob(pattern):
            # Extract date from path: sessions/YYYY/MM/DD/
            parts = filepath.split('/')
            try:
                date = f"{parts[-4]}-{parts[-3]}-{parts[-2]}"
            except IndexError:
                continue

            max_input = 0
            max_output = 0

            try:
                with open(filepath, 'r') as f:
                    for line in f:
                        # Extract cumulative totals
                        match = re.search(r'"total_token_usage":\{[^}]*"input_tokens":(\d+)[^}]*"output_tokens":(\d+)', line)
                        if match:
                            inp = int(match.group(1))
                            out = int(match.group(2))
                            max_input = max(max_input, inp)
                            max_output = max(max_output, out)
            except Exception as e:
                print(f"Error processing {filepath}: {e}")
                continue

            self.daily_stats[date]['codex_cli']['input'] += max_input
            self.daily_stats[date]['codex_cli']['output'] += max_output

    def analyze_gemini_cli(self):
        """Extract Gemini CLI token usage from JSON chat files."""
        pattern = f"{self.home}/.gemini/tmp/*/chats/*.json"

        for filepath in glob(pattern):
            try:
                with open(filepath, 'r') as f:
                    data = json.load(f)

                # Get date from file modification time
                mtime = os.path.getmtime(filepath)
                date = datetime.fromtimestamp(mtime).strftime('%Y-%m-%d')

                for msg in data.get('messages', []):
                    usage = msg.get('usageMetadata', {})
                    if usage:
                        self.daily_stats[date]['gemini_cli']['input'] += usage.get('promptTokenCount', 0)
                        self.daily_stats[date]['gemini_cli']['output'] += usage.get('candidatesTokenCount', 0)
            except Exception as e:
                print(f"Error processing {filepath}: {e}")

    def analyze_opencode(self):
        """Extract OpenCode token usage from message JSON files."""
        pattern = f"{self.home}/.local/share/opencode/storage/message/*/msg_*.json"

        for filepath in glob(pattern):
            try:
                with open(filepath, 'r') as f:
                    data = json.load(f)

                usage = data.get('usage', {})
                if usage:
                    mtime = os.path.getmtime(filepath)
                    date = datetime.fromtimestamp(mtime).strftime('%Y-%m-%d')

                    self.daily_stats[date]['opencode']['input'] += usage.get('input', 0)
                    self.daily_stats[date]['opencode']['output'] += usage.get('output', 0)
            except Exception as e:
                print(f"Error processing {filepath}: {e}")

    def analyze_kilo_code(self):
        """Extract Kilo Code token usage from embedded JSON in text fields."""
        patterns = [
            f"{self.home}/.kilocode/cli/global/tasks/*/ui_messages.json",
            f"{self.home}/.vscode/data/User/globalStorage/kilocode.kilo-code/tasks/*/ui_messages.json",
            f"{self.home}/.cursor/data/User/globalStorage/kilocode.kilo-code/tasks/*/ui_messages.json",
        ]

        for pattern in patterns:
            for filepath in glob(pattern):
                try:
                    with open(filepath, 'r') as f:
                        data = json.load(f)

                    mtime = os.path.getmtime(filepath)
                    date = datetime.fromtimestamp(mtime).strftime('%Y-%m-%d')

                    for msg in data.get('messages', []):
                        text = msg.get('text', '')

                        # Extract embedded JSON tokens
                        in_match = re.search(r'"tokensIn":(\d+)', text)
                        out_match = re.search(r'"tokensOut":(\d+)', text)

                        if in_match:
                            self.daily_stats[date]['kilo_code']['input'] += int(in_match.group(1))
                        if out_match:
                            self.daily_stats[date]['kilo_code']['output'] += int(out_match.group(1))
                except Exception as e:
                    print(f"Error processing {filepath}: {e}")

    def analyze_qwen_code(self):
        """Extract Qwen Code token usage from chat and stats files."""
        patterns = [
            f"{self.home}/.qwen/tmp/*/chats/*.json",
            f"{self.home}/.qwen/auto_stats/*.jsonl",
        ]

        for pattern in patterns:
            for filepath in glob(pattern):
                try:
                    mtime = os.path.getmtime(filepath)
                    date = datetime.fromtimestamp(mtime).strftime('%Y-%m-%d')

                    if filepath.endswith('.jsonl'):
                        with open(filepath, 'r') as f:
                            for line in f:
                                try:
                                    data = json.loads(line)
                                    usage = data.get('usageMetadata', {})
                                    self.daily_stats[date]['qwen_code']['input'] += usage.get('promptTokenCount', 0)
                                    self.daily_stats[date]['qwen_code']['output'] += usage.get('candidatesTokenCount', 0)
                                except json.JSONDecodeError:
                                    continue
                    else:
                        with open(filepath, 'r') as f:
                            data = json.load(f)
                        for msg in data.get('messages', []):
                            usage = msg.get('usageMetadata', {})
                            self.daily_stats[date]['qwen_code']['input'] += usage.get('promptTokenCount', 0)
                            self.daily_stats[date]['qwen_code']['output'] += usage.get('candidatesTokenCount', 0)
                except Exception as e:
                    print(f"Error processing {filepath}: {e}")

    def run_all(self):
        """Run analysis for all supported tools."""
        print("Analyzing Claude Code...")
        self.analyze_claude_code()

        print("Analyzing Codex CLI...")
        self.analyze_codex_cli()

        print("Analyzing Gemini CLI...")
        self.analyze_gemini_cli()

        print("Analyzing OpenCode...")
        self.analyze_opencode()

        print("Analyzing Kilo Code...")
        self.analyze_kilo_code()

        print("Analyzing Qwen Code...")
        self.analyze_qwen_code()

        return self.daily_stats

    def generate_report(self):
        """Generate summary report of token usage."""
        stats = self.run_all()

        # Aggregate by tool
        tool_totals = defaultdict(lambda: {'input': 0, 'output': 0, 'max_daily_output': 0})
        tool_daily_outputs = defaultdict(list)

        for date, tools in stats.items():
            for tool, tokens in tools.items():
                tool_totals[tool]['input'] += tokens['input']
                tool_totals[tool]['output'] += tokens['output']
                tool_daily_outputs[tool].append(tokens['output'])

        for tool in tool_totals:
            if tool_daily_outputs[tool]:
                tool_totals[tool]['max_daily_output'] = max(tool_daily_outputs[tool])

        # Print report
        print("\n" + "="*80)
        print("TOKEN USAGE ANALYSIS REPORT")
        print("="*80)

        print(f"\n{'Tool':<15} {'Total Input':>15} {'Total Output':>15} {'Max Daily Out':>15}")
        print("-"*60)

        grand_input = 0
        grand_output = 0

        for tool, totals in sorted(tool_totals.items()):
            inp = totals['input']
            out = totals['output']
            max_out = totals['max_daily_output']
            grand_input += inp
            grand_output += out

            print(f"{tool:<15} {inp:>15,} {out:>15,} {max_out:>15,}")

        print("-"*60)
        print(f"{'TOTAL':<15} {grand_input:>15,} {grand_output:>15,}")
        print(f"\nInput:Output Ratio: {grand_input/grand_output:.1f}:1" if grand_output > 0 else "")

        return tool_totals


if __name__ == "__main__":
    analyzer = TokenAnalyzer()
    analyzer.generate_report()
```

```python
def estimate_daily_cost(input_tokens, output_tokens, model='claude-4-sonnet'):
    pricing = {
        'claude-4-sonnet': (3.00, 15.00),
        'claude-4-opus': (15.00, 75.00),
        'o4-mini': (1.10, 4.40),
        'gemini-2.5-pro': (1.00, 3.00),
    }

    input_price, output_price = pricing.get(model, (3.00, 15.00))

    cost = (input_tokens / 1_000_000 * input_price) + \
           (output_tokens / 1_000_000 * output_price)

    return cost
```

## 9. Known Issues and Limitations

### 9.1 Data Accuracy

| Issue | Impact | Mitigation |
|-------|--------|------------|
| Codex cumulative totals | Over-counting by 1000x+ if summed | Take MAX per session |
| Kilo Code embedded JSON | Parsing complexity | Regex extraction |
| Missing timestamps | Cannot group by day | Use file mtime |
| Deleted sessions | Historical gaps | None (data lost) |

### 9.2 Rate Limits

| Tool | Known Limits |
|------|--------------|
| Claude Code | ~500K output tokens/day (soft limit) |
| WARP | 10,000 requests/month |
| Gemini CLI | Context-based, ~2M tokens/request |
